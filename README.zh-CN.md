## 它做什么

**它自己就开始了。** 你一进会，屏幕角上出现一条小小的录制条。等人都走了，它十秒后自己停下，
接着开始转写。整场你不用记一个字。

**它在你的 Mac 上跑。** 中文用 FireRedASR2，英文用 Parakeet。每个字对应到音频哪一秒，
是从声音本身对出来的，不是按字数估的——点任意一个字，音频就跳到那儿。中英混着说也不丢字。

**纪要是能用的。** 大多数 AI 纪要的毛病是把会又讲了一遍：看着挺完整，读的人只能再找个 AI 压一遍。
Kept 只写结果：拍了什么板、谁负责、什么时候交、还有哪件事没定。哪一条不放心，点它，
就回到当时那句话。

**它分得清谁说了哪一句。** 不少工具会把一场二十人的会全塞进一个「发言人」。Kept 把每个人拆开；
给同事录一次声纹，之后每场会自动写上他的名字。把握不够就只写「发言人 1」，绝不瞎猜。

另外还有：三种录法（只录麦克风 / 加录某个 App / 加录整台电脑）、导入现成的音视频、
FLAC 无损双轨带回声消除、全库全文搜索、导出 Markdown / TXT / 混好的音频、
可以让 Claude Code 和 Codex 直接查会议记录（只读、只给文字、默认关着）、⌥⌘R 全局快捷键。

## 隐私

除了下面这四件事，它不往外发任何东西。这份清单在 App 里原样写着，你可以打开防火墙自己数：

1. 许可证激活 / 续期 / 解绑
2. 检查有没有新版本
3. 下载语音模型（HuggingFace 或国内镜像）
4. **你自己配的** AI 服务 —— 只发文字，且要你先点同意

没有云端转写，没有 bot 进会，没有遥测。音频、声纹、屏幕内容不出这台机器。

## 准确率

| 指标 | 数字 | 测试集 |
|---|---|---|
| 中文会议字错率 | 9.3% | 自建真实会议集 |
| 说话人归属准确率 | 88.0%（英文）/ 82.2%（中文） | 25 场、15.2 小时人工标注（AMI / AISHELL-4） |
| 声纹认错率 EER | 0.26% | VoxCeleb1-O |

每发一版都重跑一遍，测法、口径、原始结果一起放出来。换模型的门槛是两项指标同时变好——
只有一项好，不换。

一小时的会大约 12 分钟处理完（含分说话人），全程不联网。

## 系统要求

- macOS 15 或更新
- Apple Silicon（不支持 Intel Mac 与 Windows：本机转写靠的是神经引擎和统一内存，
  达不到同样的速度，我们不想出一个「能跑但很难用」的版本）
- 语音模型约 1GB，首次启动时下载
